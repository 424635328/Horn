# Canvas 线稿聚合 — 图片 → 轮廓 → 碎片 → 归位

招牌效果：一张图"化成线稿飞散，再逐段归位成画"。整条管线**只在换图时跑一次**，每帧只做插值与增量绘制。
算法实现：[../scripts/vectorize.mjs](../scripts/vectorize.mjs)（含输入校验与正/负控自检，被 selftest 断言）。

## 1. 素材管线（全部一次预计算）

```
原图 → 缩到 960×540 → 灰度 → Sobel 梯度 → 非极大值抑制 → 边缘行走 → 折线路径
     → 等弧长切碎(~900–1400 片) → 预计算 Path2D/散射位/旋转角/种子
     → 全量线稿烘焙成一张离屏纹理(lineTexture)
```

- **边缘行走**：从端点（8 邻域内边数 ≤1）先走，再走闭合环；每步沿"延续上一步方向"得分最高的邻点前进。
- **抽稀**：路径点隔点取（每 2 点取 1），按总长排序后截断（`maxPaths`），短路径直接丢。
- **碎片切分**：`span = max(18, 总弧长 / 目标片数)`，沿路径按弧长切段；每片记录
  质心、相对坐标点、**确定性伪随机**散射位（sin-hash 噪声，不用 `Math.random`）。
- 确定性是硬要求：replay/scrub 时碎片必须飞向同一位置（同输入同输出，验收可逐位比较）。

## 2. 静/动分离（性能核心）

- 全量线稿预先 `stroke` 到一张 1920×1080 离屏纹理 `lineTexture`；
- 画布分两层：`staticCanvas`（已归位部分）+ `canvas`（飞行中的碎片）；
- **增量揭示**：`advanceStatic(x)` 只把 `x` 切片从纹理 `drawImage` 到 static 层，只画新露出的矩形；
- **动片抽样**：碎片再按 stride 抽到 ≤110–160 片真正参与飞行，其余直接算作"已归位"。

## 3. 飞行编排

- **归位先后跟目标 X 走**：`front = p * 1.5 - 0.25`，某片的到达度
  `arrival = smooth((front - x/W + 0.16) / 0.32)` —— 左边框先落定，脸和右边框后落定，观感有叙事顺序。
- 每片：位置 = 散射位↔归位位插值，未到达时叠加 `sin/cos(drift + seed) * 7` 漂移；
  尺寸 `0.16 + 0.84 * arrival`；旋转 `angle * (1 - arrival)`，用 `setTransform(cos,sin,-sin,cos,x,y)`。
- 所有片一批 `beginPath → moveTo/lineTo → stroke()`，避免逐片 stroke；每帧零分配。

## 4. 身份纹理（让碎片"认得"这张画）

纯轮廓聚合缺"图的影子"。把头像/雷达/标题**烘焙成一张离屏纹理**，再切 ~24 块 36px 瓦片飞出：

- 烘焙时机：预热期（warm），渲染中途绝不烘焙；
- 文字按 `getComputedStyle` 画进纹理（字号/字距/颜色随设置变化）；
- 去色只做一次：`globalCompositeOperation = 'saturation'` 铺一层灰，**不要**每帧 CSS `filter`；
- 瓦片按**几何位置**挑选（雷达环带、头像框、文字框），不读像素——避免 canvas 跨域污染，
  `file://` 图片也能工作；必须读像素时先确认同源并显式降级路径；
- 与散射片共享插值：`spread` 参数控制"身份块散开 → 轮廓碎片接棒"的交接。

## 5. 帧率无关与可重放

- 一切是 `f(elapsed)`：scrub 到任意时刻都能复现；
- 帧戳缓存：同一进度不重画 Canvas（移动碎片用 `p + drift*1e-5` 做戳，漂移期仍逐帧更新）；
- 大图不进 CSS 自定义属性（会超 token 上限、且每处复制）：解码后转 **Blob URL** 挂到一个 CSS 变量上，换图时 `revoke` 旧 URL；
- 换图流程：`img.decode()` → 重新 vectorize → 重建碎片/纹理 → 重置增量绘制游标。

## 6. 线稿 → 彩图的交接

线稿与最终图**共用 16:9 几何**（同 object-fit、同 transform-origin）：

- 聚合完成（p=1）后线稿全量铺满，随后 `colorize` 段交叉淡化（线稿 opacity↓、彩图 opacity↑）；
- 彩图可以带极缓 `scale(1 → 1.012)`（Ken Burns），但 transform-origin 必须与线稿一致，否则"错位感"穿帮；
- 可选视频背景：`loadeddata` 后在 colorize 段把 `<video>` 淡入接替静图，失败回退静图。
