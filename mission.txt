## Phase 2：[2.1] C++ Oboe 引擎与零 GC 审计 + [1.3 声场/调制底层] + [2.2 自定义工坊底层]
全面升级 `:core:audio` 与 `:core:data`：

- **[2.1] 零 GC 审计 & C++ Oboe (AAudio) Native 音频引擎**：
  - 通过 Gradle **Prefab** 集成 Google **Oboe** (`com.google.oboe:oboe`) 并配置 CMake (`src/main/cpp/CMakeLists.txt`)，实现 `OboeHornAudioEngine`（基于 `oboe::AudioStreamDataCallback`，`SharingMode::Exclusive` 优先，`PerformanceMode::LowLatency`，Float32 渲染，锁无关原子参数传递 `std::atomic`，在 C++ 层完整复刻 4 种车型 + 自定义音色 + 空间混响 + 软限幅器）。
  - 同步对 Kotlin 兜底引擎 `AudioTrackHornAudioEngine` 进行**严格零 GC 分配审计**（音频渲染循环内严禁 `new` 对象、严禁装箱、严禁 Lambda 捕获分配，全部复用预分配 `FloatArray`/`ShortArray`），并在运行时支持优先启用 Oboe（不支持或测试环境无缝降级至零 GC Kotlin 引擎），同时保留完整 JNI `@Keep` 与 R8 混淆规则。
- **[1.3 底层] 空间声场混响 & 实时气压/音高调制**：
  - 实现预分配环形缓冲区的零分配 **Schroeder/Freeverb 轻量级算法混响**，支持 3 种声学环境：`STREET`（常规街道，干声为主）、`TUNNEL`（隧道回响，长衰减+低通阻尼反射，火车鸣笛极具震撼力）、`OPEN_ROAD`（旷野远传，柔和远场预延迟与高频自然衰减）。
  - 支持实时连续表达参数 `expression: Float`（`-1.0f ~ +1.0f`，默认 `0f`）：动态调制音高微弯（±8% Pitch Bend）与气阀通气量/谐波亮度。
- **[2.2 底层] 第 5 种自定义声学预设（Pro Sound Lab）**：
  - 新增 `HornType.CUSTOM` 及 `CustomHornProfile` 数据模型（可调参数：主基频 `150Hz~3000Hz`、副基频比/双音开关、谐波丰富度 `0~1`、起音 Attack `3ms~120ms`、尾音 Release `5ms~250ms`、饱和失真度 `0~1`），通过 `:core:data` DataStore 持久化保存并支持一键恢复默认。
- **实时音频遥测接口（供 1.2 与 4.1 复用）**：
  - 在音频引擎中构建无锁/低开销的实时遥测通道，输出：实时 RMS 响度包络（`0f..1f`）、最新时域波形快照（如 256 samples 环形缓冲区）、实测输出延迟（ms）、缓冲区欠载计数（xrun/underrun count）、单帧渲染耗时（μs）及当前激活引擎标识（`Oboe C++` / `AudioTrack JVM`）。
- **Phase 2 门禁**：编写全面的 DSP 单元测试（验证 5 种音色、3 种混响模式、防削波 `[-1.0f, 1.0f]`、无 NaN/Inf、响度均衡、表达调制平滑性），执行 `./gradlew :core:audio:testDebugUnitTest :core:audio:assembleDebug` 通过后进入 Phase 3。

# Phase 1：`:core:designsystem` 打造 Apple Glass 设计系统与物理动效引擎

所有可复用设计 Token、毛玻璃原语与物理动效组件必须沉淀在 `:core:designsystem` 中（严禁散落硬编码在业务模块）：

1. **Apple 空间与排版规范**：
   - **同心圆角法则（Concentric Radii）**：严格规范外层容器圆角 `R_outer = R_inner + padding`，消除视觉错位感。
   - **苹果式清爽排版**：克制的留白层级、柔和次级透明度、**所有动态数值（Hz / ms / dB / xrun）强制启用等宽数字 `fontFeatureSettings = "tnum"`**，杜绝数值跳动时的文字左右抖动。
   - **5 大车型专属环境光色板（深浅双主题独立精调）**：
     - 汽车：钛金银 / 深海蓝
     - 火车：琥珀金 / 熔岩铜
     - 电车：极光青 / 翡翠绿
     - 摩托车：竞速红 / 炽热橙
     - 自定义：星云紫 / 虹彩靛

2. **真实多层毛玻璃 / 液态玻璃组件（`AppleGlassSurface`）**：
   - **底层真实背景模糊（Backdrop Blur）**：优先基于 Compose `GraphicsLayer` + API 31+ `RenderEffect.createBlurEffect`（或若与当前 `libs.versions.toml` 完全兼容则引入 `dev.chrisbanes.haze`）实现对**背后动态环境光层**的真实背景虚化，而非仅模糊自身前景。
   - **微颗粒噪点抗色带（Micro-Grain）**：在玻璃层叠加极微弱（1%~2%）程序化噪点纹理，消除 8-bit 渐变色带，赋予真实磨砂光学质感。
   - **方向性镜面高光描边（Specular Rim Lighting）**：1dp 左上亮、右下柔的线性/扫描渐变高光边缘；在 Android 13+（API 33+）结合 **AGSL `RuntimeShader`** 实现 Liquid Glass 风格的边缘微折射与随触摸/RMS 声压流动的镜面光晕。

3. **会呼吸的流体环境光背景（`AmbientMeshBackground`）**：
   - 在玻璃层下方绘制缓慢流动的多球柔和 Mesh 光斑背景，随当前选中车型的主题色平滑渐变过渡；鸣笛时由实时 **RMS 声压包络** 驱动光斑柔和膨胀透射过毛玻璃面板，呈现极强的苹果光学纵深感。

4. **全栈物理弹簧动效体系（`AppleMotion`）**：
   - 统一封装 Apple 风格阻尼弹簧预设（禁止交互态使用生硬线性 `tween`）：
     - `SnappySpring`（高响应切换，如胶囊滑动、开关切换）
     - `FluidSpring`（流畅展开，如灵动岛提示、BottomSheet）
     - `TactileOrbSpring`（带轻微细腻回弹的主按钮物理按压）
     - `rubberBand(offset, limit)` 经典 iOS 橡皮筋非线性阻尼函数。
   - 构建 3 个核心 Apple 级通用玻璃组件：
     - **`GlassSegmentedControl`（流体滑动胶囊选择器）**：内部悬浮一枚带高光描边的玻璃指示胶囊，切换选项时胶囊以弹簧物理丝滑滑移、伴随轻微速度形变并触发细腻触觉刻度（`CLOCK_TICK`）。
     - **`GlassCapsuleSlider`（iOS 控制中心粗胶囊滑块）**：取代传统细杆 Material Slider，采用半透明圆角玻璃槽 + 丝滑填充条 + 边界橡皮筋微拉伸反馈。
     - **`DynamicPillBanner`（灵动岛式悬浮状态胶囊）**：顶部居中紧凑悬浮玻璃胶囊，按需以弹簧尺寸形变（`animateContentSize`）丝滑展开/收起系统通知。
